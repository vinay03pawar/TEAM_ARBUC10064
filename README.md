
# MindGuard AI

## AI-Powered Mental Health Monitoring & Support System for Workplaces

MindGuard AI is a futuristic AI-driven platform designed to monitor workplace mental wellness, predict burnout risks, and provide intelligent emotional support using smart automation and analytics.

---

## Features

- AI Mood Tracking
- Burnout Prediction
- AI Wellness Chatbot
- Employee Wellness Dashboard
- JWT Authentication
- Smart Analytics
- Real-Time Stress Monitoring
- Emergency Mental Health Alerts

---

## Tech Stack

### Frontend

### Backend
- ASP.NET Core Web API

### Database
- SQL Server

### AI
- Python FastAPI
- Sentiment Analysis
